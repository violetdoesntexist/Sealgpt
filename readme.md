
# SealGPT

It's a seal! But it's in your computer... a seal-themed Discord bot!

## Description

A Discord bot that's themed around seals. I made this for a friend's server because I like seals and wanted to try building a Discord bot.

## Getting Started (with npm)

```bash
git clone https://github.com/violetdoesntexist/Sealgpt.git
cd Sealgpt
npm install

```

Add tokens to `config.json`:

```json
{
  "token": [DISCORD APP TOKEN],
  "clientId": [DISCORD CLIENT ID]
}

```
