# SealGPT

It's a seal! But it's in your computer... a seal-themed Discord bot!

## Description

A Discord bot that's themed around earless seals, it started as a very simple random message generator and eventually got to the stage its at now :3, it is still in development and i'll add features when i have ideas for fun new ones!

## Commands

Interaction:\
  /hug - hug the seal\
  /givefish - give the seal some fish\
Fun:\
  /gif - get a random seal gif\
  /random-species - get an image, the name and a fun fact about a random earless seal species!\
Utility:\
  /ping - ping the bot\
  /info - get the project infos

MORE IN FUTURE VERSIONS 

## Getting Started (with npm)

```bash
git clone https://github.com/violetdoesntexist/Sealgpt.git
cd Sealgpt
npm install

```

Add tokens to `config.json`:

```json
{
  "token": [DISCORD APP TOKEN],
  "clientId": [DISCORD CLIENT ID]
}

```
